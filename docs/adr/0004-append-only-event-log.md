# ADR-0004: Append-only Event Log
**Status:** accepted
## Решение
Синхронизируются события (конверт `domain.Event`), а не состояние. Повторная передача — идемпотентна (уникальность пары node_id+sequence). Слияние независимых записей одной лошади — только явным событием `identity.resolved` с автором и основанием; автоматического объединения нет.
## Почему
Append-only даёт порядок, устойчивость к конфликтам и восстановимость. CRDT отклонены для V0 (см. §15 ТЗ).
