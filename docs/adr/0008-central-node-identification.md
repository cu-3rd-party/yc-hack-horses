# ADR-0008: Central node identification
**Status:** accepted
## Решение
Central-возможности выдаются соединению только если: (1) SNI/hostname подключения — `yc-hack-horses.cu3rd.ru`; (2) серверный серт прошёл проверку публичного CA (не self-signed); (3) клиентский серт прошёл mTLS-валидацию. Роль `role=central` в ответах — информационное поле, не источник доверия. Конфигурация локальной ноды не может объявить её центральной: central capabilities живут только на сервере и выдаются лишь для hostname central.
## Почему
Соответствует требованию: hostname определяет ожидаемую точку, криптография — идентичность. DNS spoofing нейтрализуется проверкой валидного публичного серта на имя (нужен и контроль CA — выпуск серта возможен только у владельца домена).
