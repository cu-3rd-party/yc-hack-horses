# ADR-0010. Настольный журнал ЛошID

Electron открывает React-интерфейс по адресу `journal://app/`. По умолчанию приложение использует отдельно запущенную Go-ноду на `127.0.0.1:8080`. Главный процесс проксирует разрешённые запросы по `/api/v1` на фиксированный адрес. Оригиналы фотографий передаются в хранилище ноды. Настройки доступны и при отсутствии соединения.

Переключатель «Демосценарии» хранится в профиле приложения. В деморежиме локальный Axios-адаптер и IndexedDB обслуживают примеры, фотографии и учебный журнал. У рабочего и демонстрационного режимов отдельные кэши. Сброс демо действует только на демонстрационный журнал.
