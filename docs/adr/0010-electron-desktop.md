# ADR-0010. Настольный деможурнал

Electron открывает локальный React-интерфейс по внутреннему адресу `journal://app/`. Подготовленные фотографии и шрифты входят в пакет. Рендерер хранит архив IndexedDB в профиле приложения. Сохранение снимков, привязка особи и обновление очереди выполняются в одной транзакции.

Адаптер Axios обслуживает запросы распознавания и синхронизации локально. TanStack Query обновляет все представления после изменений. Для форматов, которые Chromium не может прочитать, изолированный preload передаёт байты нативному декодеру macOS. Сброс демоданных восстанавливает начальное состояние архива.
