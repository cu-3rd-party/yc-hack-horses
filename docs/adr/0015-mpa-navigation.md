# ADR-0015: MPA-навигация веб-интерфейса

Статус: принято

## Контекст

Веб-интерфейс (app/) — SPA без роутера: один `index.html`, активная страница —
стейт в `app/src/app/App.tsx`, навигация — клики по сайдбару. Нативная
браузерная навигация (открыть ссылку, средняя кнопка, история, «открыть в
новой вкладке») не работает. Статику раздают два хоста:

1. Go-нода (`backend/internal/transport/http/server.go`) — явный список
   маршрутов: `/`, `/assets/{file}`, `/pdfjs/{group}/{file}`, `/photos/{file}`,
   `/licenses/{file}`.
2. Electron (`app/electron/main.cjs`) — протокол `journal://app`, маппинг пути
   на файл dist/, `will-navigate` блокирует любые переходы кроме стартового URL.

## Решение

Классический MPA на Vite: по одному HTML-входу на страницу, навигация —
настоящие `<a href>` с полной загрузкой документа.

- **Входы.** `index.html` (Распознавание, корень), `gallery.html` (Особи),
  `observations.html` (Наблюдения), `system.html` (Система: Дашборд/Синхронизация/Настройки
  — остались одной страницей, под-вкладки — обычные якоря `#settings`/`#sync`,
  читаемые из `location.hash`). `models.html` и `passport-upload` сохраняются
  как есть (панель моделей — внутри system/review где была; паспорт — модалка).
- **Общий каркас.** Один `main.tsx` читает `document.body.dataset.page` и
  монтирует соответствующую страницу внутри общего shell (сайдбар + провайдеры +
  Toasts/DialogHost). Сайдбар-разделы становятся `<a>`; активная подсвечивается
  по dataset.page.
- **Go-нода.** Добавить маршруты `/{page}.html` на тот же FileServer
  (`r.Get("/{page}", ...)` — файлы лежат в корне dist; отсутствие файла = 404,
  SPA-fallback не появляется).
- **Electron.** `will-navigate` разрешает переходы только внутри `journal://app`
  (блокируем внешние схемы/хосты); маппинг файлов уже разрешает `gallery.html`.
- **Демо-режим и данные.** `useNotebook`/react-query работают постранично —
  каждая страница загружает свои данные сама; режим демо (journal/mode.ts)
  читается независимо в каждой странице.
- **Мобильное (RN) не затрагивается.** Dev-флоу `npm start` (vite dev) работает
  с MPA нативно.

## Следствия

- Нативная навигация: ссылки, история, открытие в новой вкладке.
- Чуть больше байтов на переход (полная загрузка документа) — приемлемо для
  локального интерфейса.
- `App.tsx` как роутер-стейт исчезает; страницы становятся самостоятельными
  точками входа.
