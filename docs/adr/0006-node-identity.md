# ADR-0006: Node identity
**Status:** accepted
## Решение
node_id — UUIDv4/v7, генерируется при первой инициализации ноды. Привязка к сертификату — URI SAN `przewalski://node/<node_id>` в клиентском сертификате. Не полагаемся на CN.
## Почему
Криптографически проверяемая привязка идентичности без стороннего каталога. CN ненадёжен и не предназначен для этого.
