# ADR-0011: Mobile Go Core integration
**Status:** accepted
## Решение
React Native + Go Core как нативная библиотека (gomobile bind): RN вызывает Go-функции через мост для инициализации ноды, записи событий и foreground sync (исходящие соединения). Inbound gRPC-сервер и mDNS-демон на iOS/Android в V0 не гарантированы (ограничения фонового выполнения).
## Почему
Постоянный daemon на мобильных ОС ненадёжен; встраивание библиотеки сохраняет общий код. Если упаковка RN+gomobile окажется велика для первого этапа — приоритет desktop-вертикали, но интерфейс Go Core для мобильной интеграции фиксируется и не подменяется пустой папкой.
