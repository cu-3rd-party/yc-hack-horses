# ADR-0005: Vector clock synchronization
**Status:** accepted
## Решение
Прогресс — `VectorClock` (map node_id→последний sequence каждого узла, увиденного нодой). `GetMissingEvents(remote)` выбирает события, отсутствующие у пира. Батчи с лимитом, стрим `PullEvents` + `AckBatch`, восстановление после обрыва — просто повтор с актуальным clock.
## Почему
Достаточно и просто для append-only лога без ветвления (sequence монотонен в рамках ноды). Полные векторные сравнения версий сущностей не нужны — события не конфликтуют по построению.
