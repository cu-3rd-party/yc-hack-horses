# ADR-0013: Animal identity vs trait fingerprint
**Status:** accepted
## Решение
ID лошади — UUID (стабильный). Fingerprint (sha256 канонизированных признаков) — инструмент поиска похожих TraitSnapshot, НЕ доказательство биологической идентичности. Соответствие двух лошадей — событие `identity.proposed` (кто предложил, какой fingerprint, какое основание) и `identity.resolved` (подтверждено/отклонено человеком).
## Почему
Признаки меняются с возрастом/сезоном/фото; разные животные бывают похожи. SHA-1/SHA-256 признаков как ID запрещён.
